# OrderPing

OrderPing is an order notification bot for small businesses that need instant alerts when customers place orders.

## Problem

Food vendors, fashion sellers, logistics teams, churches, schools, and small shops often receive orders through manual messages. Orders can be missed, delayed, or copied incorrectly.

## Solution

OrderPing collects order details, saves them, notifies the admin, and gives the customer a confirmation message.

## Planned Features

- Order form
- Order database
- Admin Telegram notification
- Customer confirmation
- Order status updates
- Daily order summary
- Basic dashboard
- CSV export

## Stack

- Next.js
- FastAPI
- PostgreSQL
- Redis
- Docker Compose
- Telegram Bot API

## Business Value

- Faster order response
- Fewer missed orders
- Clear order records
- Simple daily sales visibility

## Portfolio Notes

This project shows how a small automation can improve customer service and reduce manual order handling.
